# stellar-data-explorer
Overview

This project explores astronomical data using Python to investigate patterns and relationships among stellar and galactic properties.

Research Questions
How are astronomical objects distributed across different measurements?
What relationships exist between astronomical properties such as magnitude and redshift?
How do different astronomical filters compare in observed magnitude?
Dataset

The project uses astronomical data from the Sloan Digital Sky Survey (SDSS).

Tools & Technologies
Python
Pandas
NumPy
Matplotlib
Jupyter Notebook
Analysis

The project includes data cleaning, exploratory data analysis, descriptive statistics, and data visualization.

Visualizations include:

Histograms
Scatter plots
Box plots
Bar charts

Astronomical measurements explored include magnitude, wavelength, color, and redshift.

Key Findings

The analysis explores the distributions and relationships within the dataset, including differences between astronomical filters and relationships involving redshift and observed magnitude.

What I Learned

Through this project, I practiced working with real-world scientific datasets, cleaning and transforming data, creating visualizations, interpreting statistical patterns, and communicating data-driven findings.
